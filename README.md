# Trading-Risk-Manager
Java console application for evaluating trading risk by using account size, position risk, percentage being risk on account, and risk-to-reward calculations.
Trading Risk Manager V1

Features:
- Calculates maximum allowed trade risk using the 2% rule
- Calculates risk percentage
- Approves or rejects trades based on risk limits
- Calculates reward-to-risk ratio
- Grades trade quality (Poor, Good, Excellent)
- Calculates remaining risk or over-risk amount

Built using:
- Java
- Methods
- Parameters
- Return values
- Boolean logic
- Scanner input
- If/Else statements
