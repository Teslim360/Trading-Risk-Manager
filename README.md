# Trading-Risk-Manager
Java console application for evaluating trading risk by using account size, position risk, percentage being risk on account, and risk-to-reward calculations.
Trading Risk Manager

Version 1 Features:
- Calculates maximum allowed risk using 2% rule
- Calculates risk percentage
- Calculates reward/risk ratio
- Approves or rejects trades

Version 2 Features:
- Analyze multiple trades in one session
- Track total risk across all trades
- Count approved trades
- Count rejected trades
- Provide trade-by-trade analysis

Built Using:
- Java
- Eclipse IDE
- Scanner for user input
- For loops for multi-trade processing
- Methods for risk calculations
- If/else statements for trade evaluation
